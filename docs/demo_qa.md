# Agent 演示用例

> 知识库为跨境 B2B 业务示例数据（产品资料 / 认证合规 / 售后 FAQ / SOP 流程 / 询盘样例）。

在线体验：<https://sukiaoi.top>

## 用例 1：文档问题 → 调用 `query_docs`

> 问：出口欧盟需要哪些认证？

```
🛠️  用：['query_docs']
💬 答：出口欧盟需要 CE 认证，具体包括 LVD 低电压指令（安全）、
EMC 电磁兼容指令、RoHS 有害物质限制指令。储能电源和充电桩
出口欧盟必须提供 CE 证书及符合性声明（DoC）。（来源：data/认证与合规.txt）
```

## 用例 5：组合问题 → 多次调用

> 问：300 台 PS-500 出口德国的总价是多少？需要注意什么认证？

```
🛠️  用：['query_docs', 'calculator']
💬 答：需要先确认单价，再计算总价。按 PS-500 单台 128 美元的
示例单价计算，300 台约为 38400 美元。出口德国需 CE 认证与欧标
插头（CEE 7/7），并需 UN38.3 报告用于锂电池运输。
（来源：data/产品资料.txt, data/认证与合规.txt）
```

## 说明

- 工具由模型自行决定，因此个别问题可能换一种工具路线，属正常现象
- 每条答案都带来源，可追溯
- 检索相关度低于阈值时主动拒答，不编造
